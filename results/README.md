# Retained Benchmark Results

This directory stores bounded, text-only evidence for reportable benchmark
results. Human-readable interpretation lives under `docs/results/`.

Keep aggregate CSVs, manifests, compiler reports, resource records, and
checksums needed to verify a claim. Do not add benchmark binaries, build
directories, full traces, or repetitive per-row output when an aggregate file
contains the same information.

Historical or failed runs belong in Git history rather than this directory.
